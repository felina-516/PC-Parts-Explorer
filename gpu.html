Draws the pictures

GPU

The GPU, or graphics processing unit, creates the images you see on a screen. It can be built into the CPU or come as a separate card.

What it does

It draws games, videos, and other graphics. A powerful GPU can make detailed images run smoothly.

Where it goes

A separate GPU plugs into a long slot on the motherboard and sits inside the case.
