Short-term memory

RAM

RAM is the computer's short-term working memory. It holds information the computer is using right now.

What it does

It gives the CPU quick access to open apps and files. More RAM helps a computer keep more things ready at once.

Where it goes

RAM sticks click into long slots on the motherboard.
